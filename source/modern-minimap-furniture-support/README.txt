Modern Minimap - Furniture Support

Independent furniture extension for Modern Minimap.
Requires Modern Minimap, yUI/ySI, and KEYWORDS. Does not require
Local Map Overhaul or Local Map Overhaul - Furniture Support.

Scans furniture every 20 game frames and updates tracked icons on render.
Uses MinimapIcon keywords/aux vars and ySI texture assignments, supplied
by the Auto-Save Points Beds and Chairs integrations. Icons use the map's
neutral color and their own FurnitureIcons container and reference array.

Realtime Pip-Boy Map projects the same Modern Minimap UI, so these icons
also appear on its local map. Furniture icons do not appear in world-map mode.

Enable in MO2 alongside Modern Minimap. No original mod files are overridden.
Restart the game after enabling, disabling, or migrating from the combined mod.

Depends on Modern Minimap's UI templates and traits. Future changes to
that UI may require compatibility adjustments. In-game validation is needed.
